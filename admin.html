はじめての方へ(最初の1回だけ)

全部で4つのステップです。いちばん上から順番に進めてください。2回目からは、「③ お知らせ」だけ使います。

1

GitHubにサイトのファイルを置く

  1. github.com にログインします(アカウントがなければ無料で作ります)
  2. 右上の「+」→「New repository」を押します
  3. 名前に atabou-papa のような半角英数字を入れ、「Public」を選んで「Create repository」を押します
  4. 出てきた画面の「uploading an existing file」を押し、次の4つのファイルをまとめてドラッグします:
    index.html admin.html news.json config.json
  5. 画面の下の「Commit changes」を押します
2

サイトを公開する(GitHub Pages)

  1. リポジトリの「Settings」→ 左の「Pages」を開きます
  2. 「Source」を「Deploy from a branch」、「Branch」を「main」、フォルダを「/(root)」にして「Save」を押します
  3. 1〜3分待って、ページを更新します。画面に「Your site is live at …」と出れば完成です

サイトのアドレスは https://ユーザー名.github.io/リポジトリ名/、この管理ページは、その後ろに admin.html を付けたアドレスです。

3

「鍵」(アクセストークン)を作る

この管理ページが、あなたの代わりにGitHubのファイルを書き換えるための「鍵」です。

  1. GitHubの右上のアイコン → 「Settings」→ いちばん下の「Developer settings」
  2. 「Personal access tokens」→「Fine-grained tokens」→「Generate new token」
  3. 名前は何でもOK(例: admin)。期限は「90 days」などを選びます
  4. 「Repository access」で「Only select repositories」を選び、サイトのリポジトリだけを選びます
  5. 「Permissions」→「Repository permissions」→「Contents」を「Read and write」にします
  6. 「Generate token」を押し、表示された github_pat_… をコピーします(この画面を閉じると二度と見られません)
鍵は他の人に見せないでください。期限が切れたら、同じ手順で作り直すだけです。
4

この管理ページに接続する

  1. 上の「② 接続設定」を開きます
  2. ユーザー名、リポジトリ名、コピーした鍵を入れて「接続テスト」を押します
  3. 上のバッジが緑の「接続OK」になれば成功です

お知らせの出し方(いつもの操作)

▶
  1. 「③ 記事を書く」を開き、日付・種類・タイトル・本文を書いて「追加する」を押します。英語と写真は、入れなくてもかまいません(英語を空にすると、英語表示でも日本語が出ます)
  2. 下の「プレビュー」で、サイトでの見え方を確認します
  3. 画面の下の「公開する」を押します。1〜3分で、サイトのNEWSに出ます

直したいときは一覧の「編集」、消したいときは「削除」のあと、必ず「公開する」を押してください(押すまでサイトは変わりません)。

サイトのお知らせをタップすると、その記事のページが開きます。一覧の「記事を開く」で、公開後の記事ページを確認できます。記事のアドレスは「サイトのアドレス#news/番号」です。

プロフィール(BIO)の文章や年表を変えたいときは、「⑤ BIO」で編集して「BIOを保存して公開する」を押します。

困ったとき

「読み込めませんでした: HTTP 401」と出る

鍵が間違っているか、期限切れです。手順3をやり直して、新しい鍵を貼り付けてください。

「HTTP 403」「HTTP 404」と出る

鍵の権限が足りない、または対象のリポジトリが選ばれていません。手順3の「Repository access」と「Contents: Read and write」を確認してください。ユーザー名やリポジトリ名のつづり違いもよくある原因です。

公開したのにサイトに出ない

反映まで1〜3分かかります。時間をおいて、ブラウザを再読み込み(スマホは更新)してください。

「公開できませんでした: … does not match」と出る

他の場所でも更新した場合に起きます。「② 接続設定」で「接続テスト」を押して最新の内容を読み込み直し、もう一度お知らせを直して公開してください。

写真が入らない

先に「② 接続設定」で接続テストを成功させてください。写真は自動で小さく整えられ、GitHubの images/news フォルダに保存されます。記事を「公開する」まで、サイトには出ません。

英語表示にするには?

サイトの右上の「EN」を押すと、英語に切り替わります。記事に英語のタイトルと本文を入れておくと、記事も英語で表示されます。

鍵はどこに保存される?

このブラウザの中だけです。サーバーには送られません。共用のパソコンでは、使い終わったら「② 接続設定」の「設定を消去」を押してください。

お知らせの一覧

YouTubeの登録者数を自動で連動させる

サイトの登録者数・動画数・再生数を、YouTubeと自動でそろえる設定です。無料のAPIキーが必要です。

APIキーの作り方

  1. console.cloud.google.com にGoogleアカウントでログインし、上のプロジェクト選択から「新しいプロジェクト」を作ります
  2. 左のメニュー「APIとサービス」→「ライブラリ」で YouTube Data API v3 を検索し、「有効にする」を押します
  3. 「APIとサービス」→「認証情報」→「認証情報を作成」→「APIキー」を押します
  4. 作られたキーの「キーを制限」を開き、「ウェブサイトの制限」にサイトのアドレス(例: https://ユーザー名.github.io/*)を入れて保存します。「API の制限」では YouTube Data API v3 だけを選びます
  5. キーをコピーして、下の欄に貼り付けます
APIキーはサイトのファイル(config.json)に書かれ、見る人にも見える形になります。そのため、手順4の「ウェブサイトの制限」を必ず設定してください。設定しておけば、他のサイトで使われることはありません。
